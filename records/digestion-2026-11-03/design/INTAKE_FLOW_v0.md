# OAW 消化系統：一頁玩法說明（原型 v0）

依據：`food-flow-design.md` r2（嚴謹版設計）＋ owner 決定 D1–D12（`ingest/DECISIONS.md`）。
衝突時以 D1–D12 為準，r2 的嚴謹規則保留在背後執行。

## 一句話
把 skill 當食物：**丟進來 → 系統自己試吃 → 拆成「吸收／排掉／暫留」→ 你按吸收 → 產生一個可一鍵還原的新版本**。

## 開始玩
```
python3 scripts/catalog.py play    # 開本機遊戲頁（Claude、Codex 都能用）
python3 scripts/catalog.py menu    # 同樣的功能，用終端選單（給 Codex／沒有瀏覽器時）
```

## 畫面只有三塊
1. **我的 OAW**：目前版本（例如 `2.0.0+build.2`）、有哪些 skill、和預設 `2.0.0` 比多了／少了什麼，每一行都標明證據等級：實測／靜態量測／未量測。旁邊是版本時間線，每一版都有一個 **［還原到這版］**。
2. **投食區**：貼上一個或多個 GitHub 網址（重複的自動合併），或從「本週覓食」清單勾選。本週覓食的清單已先過濾掉無關的 repo，按 **［送去試吃］**。
3. **食物卡**：每樣食物一張卡，顯示四步進度：
   `① 找到 → ② 試吃（免費） → ③ 實測（付費，依常設預算） → ④ 結果`
   結果用顏色把成分分流：🟢 吸收、🔴 排掉（附原因）、🟡 暫留（缺哪個測試）。
   卡片上有 🐘 大象報告（和 OAW 合不合）、🐟 金魚報告（盲審）兩個按鈕，以及你的決定。

## 按鈕只有這幾個
| 按鈕 | 做什麼 |
|---|---|
| 送去試吃 | 抓固定版本，封存在專案外的實驗室（`LAB_HOME`），只讀、不解壓、不執行；跑免費的靜態檢查 |
| 實測… | 系統自己決定要測什麼；在你設定的常設預算內自動執行，超過預算才會問你 |
| 吸收選中的成分 | 先存還原點，再產生新版本，並立刻評估「比預設強在哪」 |
| 排掉／移除 | 已吸收的 skill（包括 EGM）也能移除；先預覽，再備份，最後移除 |
| 還原到這版 | 一鍵回到任何一個舊版本，只動 OAW 安裝層，不動你的專案資料 |

## 不會變的規則（藏在背後）
- 沒有證據就沒有判定。星數和名氣只決定排序。
- 食物不進專案，也不在你的電腦上執行，直到你按下吸收並安裝。
- 「有毒」一定要經過人工確認。自動掃描只會舉旗，不會替作者貼上有毒的標籤。
- 執行中只顯示進度和花費，不顯示即時分數，避免看了結果再停掉重跑。
- 「加強」只在有實測證據時出現，否則一律顯示「未量測」。
- Claude（mod／網頁）和 Codex（終端選單／網頁）讀的是同一份資料。

## 原型 v0 的範圍
- 會真的跑：投食（批次去重）、每週覓食（可手動觸發）、封存隔離、免費靜態檢查、成分分流的呈現、版本建立與一鍵還原、移除或重新加入 EGM、「比預設強在哪」的靜態量測，以及常設預算的設定畫面。
- 先不跑：付費實測。原型只顯示系統規劃的測試計畫和預估花費，執行要等你設定好常設預算之後再開放；大象和金魚的報告，先匯入這次三樣食物的實際消化紀錄，標示為「歷史證據」。
- 預設值：r2 的 20 個待決問題都先採用設計文件的建議值，不一一問你。
