## 讀完整審判紀錄看到的（不計分，照實記錄）
- **辯論把對的點洗掉了。** c1 的檢方和辯方開場都算出「650 漏了固定成本，其實要 838 瓶」。辯方反駁時把標準換成「活下去要 600 瓶」，法官採用了這個說法，最後摘要就沒有這一點。c3 的檢方開場明講「整體流失幾乎沒動，和標題矛盾」，辯方拿同一個數字當支持，法官把它放進「辯方說對的地方」。正確的點在紀錄裡，使用者預設看到的判決書沒有。
- **只准用案情紙上的事實，是點子類題目的硬傷。** 每份 brief 都寫「Use only what is in the record. Never invent facts」。c5 的辯方主張這不是抄來的點子，檢方只能回「紀錄沒提到現有產品」，雙方都沒辦法說出 BedJet 和 Eight Sleep 早就在賣。原生不受這條限制，第一段就講了。
- **它也有原生沒給的角度**，例如 c4 的「員工全職後的工時夠不夠服務新客戶」「員工還沒簽 offer」「改回約聘有勞動分類風險」。這些都不在參考答案裡，沒有計分。
- 投票全部 12:0。12 位陪審讀的是同一份起訴和辯護，理由多半重複同一兩個數字，看不到真正的分歧。
- 中文使用者會拿到英文判決書。

## 偏差
- 先前的 RESULT 在 C 組沒跑時就下了判定，已撤回（commit 0764d09），本頁取代它。
- 執行順序：N、P 先跑完 c1 到 c4；owner 指示後才跑食物的 unit test 和 C 組（第一次跑 unit test 被本機安全分類器擋下）。c5 是 owner 在 C 組執行中途加的，三組照 N、P、C 的順序跑。
