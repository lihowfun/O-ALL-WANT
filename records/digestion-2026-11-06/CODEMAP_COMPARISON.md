# 讓 AI 有程式碼地圖：原生、OAW、graphify、codegraph 客觀比較

2026-11-06，owner 問：「請你做 codegraph、graphify 還有我們自己的……讓 AI 有程式碼地圖的話，請幫我客觀的比較。」

## 一句話
**三個地圖都沒有讓 AI 答得更準。** 差別只在花多少：codegraph 最少走步（工具呼叫最少）；OAW 自己的 `code_index.py` 在三個地圖裡最省 token；graphify 兩樣都沒贏，而且在 Opus 4.8 上變差。三個地圖在多數條件下都比原生多花 token。

## 怎麼比的（四組條件相同）
- 同一個大型陌生 repo（ERPNext @ d9cb916），同一組 4 題凍結題目（2 題影響、1 題流程、1 題機制，sha256 `b7604bca…`）。
- 每組各自一份副本，照各自官方方式裝好：
  - OAW：`code_index.py` 加一段 CLAUDE.md 說明。
  - graphify：官方 project 安裝，含 hook 和規則。
  - codegraph：官方 project 安裝，含 MCP、prompt hook 和 CLAUDE.md 段落。
  - 原生：只有 Read、Grep、Glob。
- 4 個模型條件：Opus 5.5 和 Sonnet 5.5 每格 3 次；Opus 4.8 每格 3 次；Haiku 5.5 每格 1 次。
- **同一個條件的四組答案在同一批盲評**：零上下文的 Opus 5.5 評分者，看不到組別。
- 訂閱計費，Claude Code 2.1.287。

## 各自的特點（看原始紀錄得到的）
- **codegraph**：
  - 它的 prompt hook 每題一開始就塞約 8k token 的相關程式碼，所以 agent 直接去讀對的那幾行，步數最少。
  - 但 agent 從來沒有自己呼叫 codegraph 的工具，還是會用 grep、sed 核對。開頭塞的內容之後每一回合都會再讀到，所以 token 比較多。
  - 它宣稱「token 少 62%」，這裡沒有重現。
- **OAW code map**：
  - `callers` 一次列出所有呼叫者，在「找影響範圍」的題目最有用（Opus 5.5 q1：7 次工具呼叫，原生 31 次）。
  - 在 Opus 4.8 上沒有少走步。
- **graphify**：
  - 查詢結果是截斷過的子圖，比較弱的模型會照著截斷的結果作答、漏掉呼叫者。Opus 4.8 的影響題掉最多。
- **光給原生 Bash 沒有用**：原生加上唯讀 Bash，工具呼叫並沒有減少（9.25 對 9.67）。所以地圖組少走的步數，確實是地圖的功勞。

## 裝起來的負擔
| | 執行環境 | 索引 | 會改的設定 |
|---|---|---|---|
| OAW code map | Python 標準函式庫，一個檔案 | 快取建一次約 23 秒，之後每次呼叫約 4 秒，改過的檔案自動更新 | 專案 CLAUDE.md 一段 |
| graphify | Python 套件（pip） | 事先建圖 | 專案 CLAUDE.md、skill、PreToolUse hook |
| codegraph | Node 執行環境、MCP server | SQLite 索引 189 MB；本機 SSD 15 秒，網路磁碟（NFS）15 分鐘還沒建完 | 專案 `.mcp.json`、settings hook、CLAUDE.md 段落；家目錄留下一個空資料夾 |

## 建議
- **不另外接上 codegraph 或 graphify**：OAW 已有的 `code_index.py` 做得到 codegraph 的主要好處（少走步），而且 token 更少、不用多裝東西。
- **「先查地圖」不寫進預設規則**：三個地圖都沒有讓答案更準，token 又多半更多。`code_index.py` 保留給 agent 自己選用，適合「找所有呼叫者、改了會影響哪裡」這類問題。

## 限制
- 只有 4 題；每格 3 次（Haiku 1 次）。
- Opus 5.5 原生幾乎滿分，「更懂」沒有空間。
- 錯誤陳述是 AI 評分，同一批答案評兩次會差 0 到 2 個，所以 OAW 和 graphify 在 Opus 4.8 的判定曾經因為評分批次而翻轉。本頁全部用同一條件、同一批評分的數字。
- 細節：`taste-codegraph/RESULT.md`；graphify 和 OAW 的原始作答在 `../digestion-2026-11-03/codemap-erpnext-confirm/`、`codemap-erpnext-weaker/`。
