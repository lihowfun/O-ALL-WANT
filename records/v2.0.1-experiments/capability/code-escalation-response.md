gpt-6-astra 和 Fable 5.1 各自獨立看了第 3 次修改後的版本，都判「先改再跑」。兩位都確認第 3 次的 28a、28b、29–33 已關閉。各自新提的點和處理如下（兩位的編號各自從 34 起算，前面加 A、F 區分）。

| # | 嚴重度 | 指出 | 怎麼改 |
