# 凍結前修正 2 的核對（Codex gpt-6.1-sol，範圍限定，2026-11-12）

## 第一次

修正不可以
- `median_ground()` 有漏判：Linux 記憶體測試中，半數筆畫黑字黑底，`measure()` 的整框與字詞覆蓋率仍是 1.0；須檢查筆畫所在處的局部對比，不能只用整個字詞框的中位數。
- FK／FW 同時改所有圖表，重疊圖表的上層文字可能替被遮住的下層文字提供差異像素；須逐圖表只改目標文字。
- `size_min` 從全圖表字級集合回填，會混入未使用的設定；例如實際 16 點回報 15，集合含閒置 15 點便誤判。須對應實際文字及有效樣式。
- 保留原成品重評合理，但 `cmd_regrade()` 會直接跳過已有結果，容許先重跑部分校準再混入舊成品；須拒絕非同源重評紀錄，固定來源並拒絕重複來源列。
- 同一程式適用各組仍不足以保證公平：上述問題會放過低對比或重疊圖表，並使含閒置字級設定的正常圖表吃虧。
- 指定反例未涵蓋上述情境，須補驗；本次僅做靜態核對與記憶體測試，未修改檔案、未重跑算繪。
