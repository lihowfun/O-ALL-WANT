## 疑點（給 owner）

1. **天花板與回退的解讀**：N 已達 97.92%，最多只剩 2.08 個百分點改善空間，低於登記的偵測門檻。維持 N 是凍結規則的部署回退；本研究無法據此推論大型設計、較難案例或下游實作品質。兩格 N 本身各有一個乾淨案誤報，維持 N 也不等於認證 N 沒有誤報。
2. **指控下限的非對稱敏感度**：我仍認為，借用值來自其他案例，借用資料也沒有重複 Codex 作答，不足以完全免除借用值的不確定性。全部 ×1.5 會使 codex E 的此項門檻失敗（Codex 上界 0.620）；本次正式判定仍完全採凍結版本。
3. **流程與核實證據較弱**：≥5 次啟動不足以證明 EGM 各階段完成或 context 全新。核實只靠 ledger 先後綁定、未綁定當時內容雜湊；失敗的出題／核實呼叫也缺完整紀錄。migrations、loyalty 修兩次，以及 loyalty 保留額外缺陷，都是凍結前已明記的偏離，這次照凍結 spec 納入；「額外缺陷只會增加校準雜訊」不是可保證的統計結論。
4. **判定程式的核對與輸出範圍**：程式未自行重算提示雜湊或現存案例 digest，也沒有保存敏感度逐組明細。本次另行核對這兩類輸入，並用凍結統計函式補存敏感度數字，未改程式或規則；未發現會改變本次判定的程式錯誤。
