# Source: Figma's PM OS (interview)

- Podcast "How I AI" (host Claire Vo), guest Ezra Mechaber (PM, Figma). The owner pasted a Chinese summary of the
  episode on 2026-11-08. The pasted text stays local; this page keeps only what the screen needs.
- Food type: an interview (ideas, no code). It is screened like a paper (SKILL_INTAKE step 2): no verdict on an idea
  until a unit built from it has been measured (D25, D28).
- Claimed ideas, in the source's order: a shared PM repo with 31 skills; agent.md + per-person context + memory read
  at session start; a start hook that checks for a new version; a parent repo plus private per-person child repo;
  "who owns this" (people and code ownership); "what's up" (what I owe, open decisions; run ~6 times a day); a
  detailed spec skill that walks the codebase; build-artifact (HTML templates); FigJam generator with encoded taste;
  coach skill; skill lifecycle (explosion, public roast, pruning as models improve; no telemetry); terminal -> web
  front end -> Codex; bug bash by a Codex browser agent from a written plan (found 1,000-emoji crash and a/an copy
  bug); AutoXP (data agent -> copy agent -> engineer agent, one human checkpoint before launch, automatic return to
  analyze results); Jev, a fast cheap model that answers text questions with a number or yes/no, used on every pause
  to flag unfinished thoughts and unsupported claims and back them with retrieved quotes.
- Owner question added at entry (2026-11-08): could some of our steps, including review, use a Jev-like model to
  give a more precise yes or no?
