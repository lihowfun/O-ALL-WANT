**Calibration against what actually exists:** [V3 expected.json](OAW-records/records/digestion-2026-11-07/validation/v3/expected.json) contains **24 answers, 116 known fact-label cells, but only four underlying questions**. Variants e/f are paired wrong-claim probes, not fully gold-labeled natural answers. [score.json](OAW-records/records/digestion-2026-11-07/validation/v3/score.json) reports 100% simple-label accuracy for all four grader runs, but full injected-pair detection ranges **50–100%**. The existing 90%/75% calibration floor is inadequate for automatic clearance.

Use the **18 archived EGM reports**, their [frozen rubric](OAW-v2/evals/egm-local/spec.json), and court references next. Existing Opus/Codex agreement is a comparison target, not truth: adjudicate disagreements against sources before creating holdout labels. Split by original question/case, not by paraphrased answer; test original/reversed reference order, negation, superseded ADRs, and instruction-like source text.

Record per-class confusion matrices, abstention/coverage, critical misses and false credit, score bias, verdict flips, p50/p95 latency, and total grading cost including escalations. A claimed <1% critical miss rate needs roughly **299 independent critical cases with zero misses** for a one-sided 95% bound; four questions or three EGM cases cannot establish it.

**Must not use it for:** automatic “safe to merge,” finding suppression, permission/consent, licensing clearance, execution isolation, replacing hidden tests, statistical calculations, or standalone intake adoption/rejection. Under current D32, a calibrated smaller judge could eventually occupy **one** family’s grading slot; two cheap calls from one family do not replace independent families. No API, new routing, or subscription entitlement should be assumed.

**3. Ranked picks — two units only**

1. **I18: offline judge-calibration adapter — A.** Extend the existing calibration machinery to validate candidate label files, expose per-class errors/abstentions, and report cost without launching models. **Frozen JUDGE test:** reproduce all four archived V3 graders’ existing accuracy and injected-delta metrics exactly; correctly identify 24 answers/116 known cells; reject missing/unknown labels, malformed schemas, and not-run grades rather than converting them to zero. **Cheapest first step:** specify input/output fixtures from existing JSON; zero model calls. Candidate-model admission later requires the F/S bars above and total grading cost ≤50% of the corresponding full-model route, including escalation. Passing this unit does not install a judge.
2. **I16: bounded adversarial bug-bash recipe — B.** Specify scenario, preconditions, actions, expected result, observed evidence, and reproducible defect report. Start with OAW CLI journeys; use an existing host browser only as a separately scoped extension. **Frozen BASH test:** 12 black-box journeys—six seeded defects and six clean controls—including 1,000 emoji, long/malformed input, recovery, and state consistency; native, description-only, and full recipe under equal tools/budgets. Pass only if both grader families find detection coverage better, unsupported findings not worse, zero missed seeded critical defects, and cost upper CI ≤1.5× native. **Cheapest first step:** map existing regression cases to user journeys and mechanically verify each oracle before model trials. If native already saturates, there is no demonstrated recipe benefit.

**4. Where OAW is worse**

- **Review has outrun its stopping rule.** The [execution plan records 18 rounds](OAW-v2/docs/plans/v2.0.1-execution.md:24), although the workflow specifies at most three. Later rounds kept producing edge-case P2 findings. Figma’s reported consolidated checkpoint is a better operating discipline; OAW should measure useful defects per review cost and enforce a stopping rule.
- **Evaluation preparation can consume the experiment.** [X1 spent about 22M tokens on question authoring and paused before formal answers](OAW-v2/docs/plans/v2.0.1-execution.md:22). Figma reports repeatedly exercising real launch scenarios. OAW needs more reusable, task-grounded cases and less expensive bespoke preparation.
- **The default review choice outruns broad evidence.** [EGM’s measured gain is narrow and costs about 28× native](OAW-v2/docs/plans/v2.0.1-execution.md:65); X2 alternatives remain unmeasured. Figma’s willingness to delete overspecified procedures is the right lesson. This does not justify removing EGM without the required comparison.
- **The surrounding workspace still feeds placeholder context.** Root `CLAUDE.md`, `AI_CONTEXT.md`, and `CURRENT_STATE.md` contain template material that I was required to read. The interview describes reading actual person/team context. V2’s on-demand policy is better, but this installation has not completed that transition.
