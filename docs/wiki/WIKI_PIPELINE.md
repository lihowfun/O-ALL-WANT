# Wiki maintenance pipeline

1. Gather a relevant source and retain its provenance, date and scope.
2. Update the raw note for the target topic, or propose a manual authored topic.
3. Render with `wiki_sync.py refresh TOPIC`; inspect the resulting source references and retained annotations.
4. Run lint and verify the substantive claims against their sources/current code.
5. Share reviewed durable knowledge. Mark superseded conclusions and keep replacements traceable.

The renderer is deterministic maintenance; factual synthesis remains an explicit author/reviewer task. Native memory, agent sessions and personal preferences remain outside this pipeline. See [Wiki Sync Guide](../Wiki_Sync_Guide.md).
