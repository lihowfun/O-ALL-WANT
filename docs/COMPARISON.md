# Where OAW fits

OAW is a portable project knowledge and verification toolkit, not another agent runtime.

| Need | Prefer |
|---|---|
| Model reasoning, tools, sessions, resume and compaction | Native Claude Code, Codex, or the selected host |
| Personal preferences and selective cross-session memory | Host memory, when supported and enabled |
| Team-owned decisions and evidence with code review | OAW/project documentation |
| Deterministic raw-to-wiki assembly | OAW knowledge profile |
| Fixed evidence comparison for a proposed workflow change | Optional OAW improvement profile |
| A headless product with durable execution and approvals | A host SDK/app-server or a dedicated workflow runtime after validating the need |

v2 adopts standard skills, bounded outputs and lifecycle ownership boundaries from current harness designs. It does not install Pi, Hermes, Deep Agents, OpenCode, OpenHands or LangGraph as dependencies. Additional adapters should follow real users and measured needs.

Product comparisons use EGM, OAW v1 and OAW v2. V2 includes EGM; within-V2
ablations disable named components to test their incremental contribution.
Shared tasks use the same facts and ordinary host tools. Product-specific
installation checks are reported separately, never scored as another product's
failure. Historical selected-vs-all-Markdown estimates do not establish a
current cost/quality advantage.
