# Codex EGM experiment — 2026-10-29

> Historical version-specific record. Current V2 includes EGM; current product acceptance uses
> `docs/SHARED_ACCEPTANCE_PROTOCOL.md`. Original arm names, source pins and results below remain unchanged.

**The combined OAW+EGM arm matched native on this fixed suite. The overall
registered promotion/merge gate did not pass:** standalone EGM produced one
additional false factual assertion. Keep PR #4 Draft and OAW 2.0.0 proposed.
No new release or default EGM runtime adoption follows from this experiment.

## Result

| Arm | Primary reviews | Fresh child contexts | Critical detections | Major detections | Unsupported concrete claims |
|---|---:|---:|---:|---:|---:|
| A: native | 9 | 10 | 12/12 | 12/12 | 0 |
| B: native + EGM | 9 | 81 | 12/12 | 12/12 | 1 |
| C: B + installed OAW guidance/evidence | 9 | 81 | 12/12 | 12/12 | 0 |

All 27 primary reviews completed, all requested stages completed, every original
workspace file remained unchanged, and all reports met the 900-word cap.
Both graders found no valid additional defects; the clean case had no false
explicit contradictions in any arm.

- B versus A: fails the zero-increase false-claim condition (events: +1).
- C versus B: observed non-regression; one fewer false claim.
- C versus A: identical measured detection/false-claim counts on these cases.
- No OAW-indexing causality claim: the registered plain-index control and
  memory-removal ablation have not run. The numerical C/B difference could be
  sampling variation or another part of the configured guidance.

The native arm already found every planted defect, so this suite has a ceiling
for demonstrating increased recall. One observed false claim does not establish
that EGM is generally worse. It does fail the strict rule fixed for this study.

## The disputed assertion

In `events-r3-B` (anonymous R05), the review said the rollout lacked a failure
trigger. The source explicitly gives failure after acknowledgement as a rollback
condition. That condition is coarse; its absence is still a different assertion
from missing measurable detection/rollback criteria.

Two fresh graders disagreed about whether the surrounding conditional-risk
qualification exempted this clause. A third fresh blinded adjudicator classified
the factual absence assertion as contradicted, while preserving the conditional
exposure observation and every agreed detection label.

## Frozen method and execution

The [registration](../../evals/egm-local/spec.json) is `oaw-egm-local-v4`, SHA-256
`d108b3a9e5993ef7aceabb9a790b3bad3e1d749bfe0ffe8336e2ff6454c66ad2`.
OAW scripts/templates digest:
`a4ee3c46ac5fd15b45cd7218959bd4ea6d420da7c48b7493e3446a936705f0c7`.
Cases, review/grade prompts, rubric and parity rules remained unchanged.

Three authored cases, three repeats and a fixed balanced dispatch order. Every
arm explicitly received the same README, design, code and current ADRs. C added
real minimal OAW files and a source-linked note; the clean case's historical
storage note had to be checked against a superseding accepted exception.

B/C used the official `Subflow: Uninterrupted Full Flow`: nine direct fresh
reviewers across five stages (1+1+3+1+3), parent synthesis, no iterative fixes or
review-loop convergence claim. Every primary and Goldfish context requested
`fork_turns=none`, inherited model/effort, no overrides. A could use up to nine
fresh reviewers too; actual compute differed, so workflow and additional compute
are not isolated as causes of quality differences.

The API did not expose an exact provider model revision. This is not a named
Opus/Sol benchmark. Agent contexts are not API requests; comparable tokens,
billing and per-trial wall time were unavailable. No efficiency claim is made.
Claude CLI F1/F2/F3 and external paid model APIs were not invoked. Codex quota
was used with the user's authorization.

Two fresh graders per case saw identical anonymous reports, source and rubric,
without exposure/arm mapping. Inputs were hash-checked before and after grading.
Only the disputed false-claim label was adjudicated; all agreed labels stayed
unchanged. Original grades and the unblinding map are retained.

A separate non-secret conversation canary was recoverable by an inherited
context and returned `UNKNOWN` under `fork_turns=none`. This checks conversation
inheritance on this API; filesystem, configured memory services and native plugin
auto-discovery remain separate. Own-trial artifacts were permitted where the
workflow needed them, including Stage 8. Fresh context is not filesystem isolation.

changes to frozen cases/rules. Graders used the same inherited configuration,
so correlated judging errors are possible. The grading-context failure is a
concrete example of that risk.

## Adoption decision

Keep the native-first minimal default. This suite does not justify making the
nine-reviewer EGM flow mandatory. Retain the complete official plugin as an
optional design-review workflow, with explicit source identity and measured
scope. The catalog/scout/runtime installer remains unimplemented.

Before an indexing-effect claim, run the registered plain-index and memory-removal
controls. A future broader study should use opaque case names, held-out realistic
long-context tasks and a compute-matched native control. The current strict merge
gate stays failed; main and releases remain unchanged.
