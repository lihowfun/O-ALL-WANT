# OAW 2.0.0 proposed — source and version ledger

Reviewed 2026-10-29. This is a Draft PR, not a tag or release. The
[machine-readable ledger](2.0.0-sources.json) records full commits, raw Git-blob
SHA-256s and usage status. A source citation is not a dependency installation or
a model benchmark. See the [EGM review](../reviews/2026-10-29-pr4-egm.md).
The existing version gate checks ledger/release agreement, full source commits
and active CI `uses` pins. It does not fetch upstream or certify blob contents;
the EGM hashes were checked against the cited raw Git blobs during this review.

## Historical influences: upstream versions were not recorded

Context Hub, MemPalace, the Karpathy wiki gist, Garry Tan's thin-harness writing,
RTK, Pi, Deep Agents, Hermes and the retired self-improver pattern are conceptual
lineage in the existing documents. Those historical records lack upstream
revision pins. Their repository links are reading pointers, not reproducible
versions, bundled components, compatibility claims or measurements.

The ledger marks this gap explicitly. It does not assign today's HEAD to an old
adoption event or treat v1 claims as a tested v2 integration. If code or skill
content is actually imported in a future change, add its exact revision, paths,
license, modifications and validation in that change. Preserve historical
documents as history rather than fabricating their provenance.
