# OAW examples

- `minimal-project/`: the five-file minimal framework payload plus install metadata.
- `public-hybrid-demo/`: knowledge and optional improvement tools, with curated source/topic examples.

Framework files come from `scripts/sync_examples.py --write` and are checked by the
local/CI gate. Curated domain notes are examples, not authoritative current project
state. Native host discovery/model behavior requires separate validation.
