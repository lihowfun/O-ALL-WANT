# Minimal OAW v2 project

Generated framework files demonstrate `python scripts/oaw.py init --target PROJECT`.
The installation has a short shared policy, Claude compatibility import, one native
project-evidence skill, and Context Hub. No placeholder project state is required.

Framework files are generated by `python scripts/sync_examples.py --write`.
Check native skill discovery in your chosen host; copying project policy alone
is not Claude skill registration. See ../../docs/Skill_Guide.md.
