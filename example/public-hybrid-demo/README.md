# OAW knowledge and improvement example

This project combines the knowledge profile and optional improvement tools with
curated ingestion/router experiment notes. The domain notes are illustrative
historical material; framework files use the v2 installer payload.

```bash
python3 scripts/context_hub.py memory recall "router" --json
python3 scripts/wiki_sync.py lint
python3 scripts/improvement.py --help
```

Framework policy, native skill packages and scripts are generated by
`python3 scripts/sync_examples.py --write` from the framework root.
The generation preserves curated docs and
experiments, while removing obsolete v1 framework copies. Improvement evaluation
artifacts belong in ignored/local state, not this public example.
